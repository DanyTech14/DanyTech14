## O que faço

| Área | O que significa na prática |
| :--- | :--- |
| 🎨 **Design Gráfico** | Identidade visual, UI/UX, composição e prototipagem no Figma |
| 💻 **Front-end** | Interfaces responsivas e acessíveis com HTML, CSS, JS, TypeScript e React |
| ⚙️ **Back-end** | APIs, bases de dados e autenticação com Node.js, Python e Supabase |
| 📱 **PWA** | Apps instaláveis, rápidas e com funcionamento offline |
